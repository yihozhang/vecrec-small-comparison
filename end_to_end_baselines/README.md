# end_to_end_baselines/

Full-pipeline VecRec kernel swaps for three real aligners. Each replaces the
aligner's SIMD DP kernel with a VecRec-generated one, keeping all surrounding
pipeline logic (seeding, chaining, SAM output) unchanged.

## Quick reference

| Aligner | Mechanism | Build | Benchmark |
|---------|-----------|-------|-----------|
| minimap2 | `ar d/r libminimap2.a` | `build_minimap2.sh` | `run_e2e.py` |
| BWA-MEM2 | `ar d/r libbwa.a` | `build_bwa_mem2.sh` | `run_bwa_e2e.py` |
| Bowtie2 | Exclude `aligner_swsse*.cpp` | `build_bowtie2.sh` | `run_bowtie2_e2e.py` |

Run the benchmark scripts for current numbers -- they aren't hardcoded here
since they drift as the VecRec kernels and baselines change. General shape
to expect: the vectorized win is largest on ARM/NEON (Clang); on x86 the
scalar VecRec DP path (GCC) runs close to parity with the hand-tuned Intel
AVX2 code.

**Requires Clang 18 on Linux** — VecRec templates use Clang-only SIMD builtins.
See root `CLAUDE.md` for the download URL and Ubuntu 24.04 `LD_PRELOAD` workaround.

## Running everything (Linux, one-shot)

```bash
# Set up Clang 18 first (see CLAUDE.md), then:
bash end_to_end_baselines/scripts/build_and_run_linux.sh
```

## Running individually

```bash
# minimap2 (works on both ARM and x86)
bash end_to_end_baselines/scripts/build_minimap2.sh
uv run python end_to_end_baselines/scripts/run_e2e.py --reps 10

# BWA-MEM2 (x86, requires Clang 18)
bash end_to_end_baselines/scripts/build_bwa_mem2.sh
uv run python end_to_end_baselines/scripts/run_bwa_e2e.py --reps 5

# Bowtie2 (x86, requires Clang 18)
bash end_to_end_baselines/scripts/build_bowtie2.sh
uv run python end_to_end_baselines/scripts/run_bowtie2_e2e.py --reps 5
```

## Generated files

Files under `generated/` are rebuilt by the corresponding `generate_*.py` script
on every build. Only the **handwritten wrappers** (`ksw2_vecrec_ext.cpp`,
`bandedSWA_vecrec.cpp`, `aligner_swsse_vecrec.cpp`) are committed to git.
The kernel headers (`vecrec_*.h`) are gitignored — always run the generate
script before building.

## Data files

`data/mt_reads.fq` is the primary benchmark dataset: 200 reads × 1000bp from
the human mitochondrial genome (MT-human.fa), generated by
`generate_test_reads.py`. All three benchmark scripts default to this file.

**Bowtie2 note**: use `mt_reads.fq` (1000bp), not `yeast/chrXII_reads.fq`
(10000bp). The current scalar DP in the Bowtie2 VecRec wrapper runs out of
headroom for very long reads.

## Integration details

See the per-aligner CLAUDE.md files for deep dives:
- `minimap2/CLAUDE.md` — DP math (anti-diagonal coordinate system, U/V/X/Y encoding), VecRec integration, z-drop limitation
- `bwa_mem2/CLAUDE.md` — SeqPair API, h0 seeding, len1/len2 convention, ARM vs x86
- `bowtie2/CLAUDE.md` — SSEMatrix layout, NWORDS_PER_REG bug, align() dispatch, backtrace
