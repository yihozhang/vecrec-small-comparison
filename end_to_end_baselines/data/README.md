# end_to_end_baselines/data/

Test datasets for the end-to-end aligner benchmarks. This is the single data
folder; the minimap2 comparison harness selects sets via
`end_to_end_baselines/minimap2/datasets.py` (regenerate synthetic sets with
`make_datasets.py`).

## Reference

- **`MT-human.fa`** — human mitochondrial genome (~16 kbp), committed here as the
  canonical reference (a copy of the one bundled with the minimap2 tree). Used by
  `generate_test_reads.py` and the default `--ref` of the run scripts.

## minimap2 comparison datasets (see datasets.py)

| Dataset | Ref + reads | Regime | Notes |
|---------|-------------|--------|-------|
| `parity-smoke` | `MT-human.fa` + `mt_reads.fq` | smoke | 200 x 1000bp; correctness/parity smoke test |
| `sv-fair` | `yeast/chrXII.fa` + `sv_reads.fq` | fair | large-extension SV reads; ~2000^2 gap-fills |
| `tandem` | `tandem_ref.fa` + `tandem_reads.fq` | fair | 200 x 15kbp over a 50-copy tandem repeat |
| `crossspecies-real` | `realbench/salmonella.fna` + `realbench/ecoli_contigs_50k.fq` | fair | real ~15-20% divergence (asm20); genomes fetched into `realbench/` (gitignored) |

"fair" marks datasets run in the no-band / no-z-drop / no-approx-max regime that
the VecRec drop-in supports (see `end_to_end_baselines/minimap2/CLAUDE.md`);
"smoke" marks small correctness/parity checks.

Regenerate the synthetic sets:

```bash
uv run python end_to_end_baselines/minimap2/make_datasets.py         # all
uv run python end_to_end_baselines/minimap2/make_datasets.py sv-fair # one
```

## Other MT-human read variants (shared with BWA-MEM2 / Bowtie2)

`mt_reads_long.fq`, `mt_reads_noisy.fq`, `mt_reads_e1/e2/e3.fq`,
`mt_reads_xspecies.fq` — clean/noisy/divergent variants used by the other
aligners' sweeps. In minimap2 terms these are mostly small-DP or out-of-regime
(divergent -> banded), so they are not part of the minimap2 dataset set above.

## Yeast data (`yeast/`)

S. cerevisiae R64 reference/reads for Bowtie2 (and the `sv-fair` reference
`chrXII.fa`). See files in `yeast/`. Note `chrXII_reads.fq` is 10 kbp reads.

## Ignored artifacts

Index sidecars are regenerated by the build/run scripts and are gitignored (see
`.gitignore`): BWA-MEM2 `*.fa.{0123,amb,ann,bwt.2bit.64,pac}` / `*.fna.*`,
Bowtie2 `*.bt2` (newly built), and BWA-only ad-hoc `mt_reads_vol*.fq`. Downloaded
cross-species genomes under `realbench/` are gitignored too.
